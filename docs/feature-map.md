# Feature map

Every user-facing feature of this site (the yeoux.net hub), how a visitor reaches it, how to drive it, and what a correct result looks like.

How the verifier uses this file: each row is one feature. A row is selected when a changed file in the PR matches one of its paths, and the row marked `yes` in Smoke is always selected. `<base>` is the app URL the verifier started locally, for example `http://localhost:4502`. Both checkouts are seeded with the same invented content by `verifier/seed.mjs`, and the drive tool is `verifier/drive.mjs`.

Seeded content, invented and local only:

- reports: `aa11bb22-quarterly-tiles.html` titled "Quarterly tiles", `cc33dd44-shipping-notes.html` titled "Shipping notes", `ee55ff66-heavy-week.html` titled "Heavy week", `99887766-ci-performance-sample.html` titled "CI performance sample"
- explorations: `11223344-route-study.html` titled "Route study", `55667788-label-test.html` titled "Label test"
- AI Movers day: `2026-02-03` with twenty shown stories (`0000000000000001` to `0000000000000020`) and three reserves (`0000000000000021` to `0000000000000023`). Story `0000000000000020` is already covered, so it sorts last and shows no buttons.
